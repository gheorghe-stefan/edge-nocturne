# edge-nocturne

Low-light & nocturnal computer vision pipeline for Raspberry Pi and IR cameras, running on-device object, person, and wildlife detection.

## Tech Stack
- **Edge ML**: Python, TensorFlow Lite, OpenCV
- **Backend**: FastAPI, SQLite, MJPEG Stream
- **Frontend**: React + TypeScript (Vite)
- **Target Hardware**: Raspberry Pi 5 (8GB) + Arducam 1080P Day/Night USB Camera
